ROWLIE'S REALITY CHECK V10 — BACK BUTTON + LARGE SEARCH CRITERIA

NEW IN THIS VERSION

1. LARGE SEARCH CRITERIA BANNER
Each search now has a large navy/yellow banner such as:

SEARCH CRITERIA
FUNCTION SEARCH

This makes it much clearer that each of the five rounds uses a DIFFERENT way to search.

2. BACK BUTTONS
Students can move backward if they need to fix something.

On the five search rounds:
- BACK reopens the previous search.
- The exact wording the student used is restored to the editable search box.
- The previous result is removed from the meter.
- When the student searches again and chooses YES / SORT OF / NOT YET, the corrected attempt replaces the old one.

From Closest Match:
- BACK reopens Search 5 so it can be corrected.

From Similarity:
- BACK returns to Closest Match.

From the final decision:
- BACK returns to Similarity.

3. SEARCHES ARE STILL EDITABLE + SAVED
Every search has:
- a different search criterion
- a suggested starting search
- an editable search box
- the exact student wording saved
- YES / SORT OF / NOT YET result

SEARCH CRITERIA
1. Direct Name Search
2. Function Search
3. Problem / Solution Search
4. Target User + Function
5. Already Exists / Competitor Search
